| 직관 코스 추천 순서 | sequence | [HTML](course_sequence.html) | [GIF](../images/course_sequence.gif) | [SVG](../images/course_sequence.svg) |
| 데이터 수집 · 전처리 · 인덱싱 | dataflow | [HTML](data_pipeline.html) | [GIF](../images/data_pipeline.gif) | [SVG](../images/data_pipeline.svg) |

- README 의 흐름도 그림을 누르면 SVG 가 열려 확대해도 선명하게 볼 수 있습니다.
- GitHub 는 레포 안의 HTML 을 실행하지 않습니다. HTML 은 내려받아 브라우저로 열면 **Present**(발표 화면) · **Play story**(단계별 설명) · 노드 클릭 · 검색이 됩니다.
- 뷰어 오른쪽 위 **Export** 메뉴에서 PNG · SVG · 영상(WebM)을 바로 내려받을 수 있습니다.
