# 야구 기초 규칙 요약 (초보자용)

작성 기준일: 2026-09-06 / 보강: 2026-09-07(1차 보강 후 분량 축소 반영)
용도: KBO 직관 안내 챗봇이 "야구 처음 보는데 뭐부터 알아야 해요?" 같은 질문에 답할 때 근거로 쓰는 문서. 크롤링 없이 공개된 일반 상식을 팀이 직접 재구성해서 작성함(원문 그대로 복사한 부분 없음).

구성: 1부(일반 야구 상식) / 2부(KBO 리그 고유 규정) / 3부(직관 관람 실전 팁) — 2부·3부는 핵심만 짧게 정리.

---

# 1부. 일반 야구 상식

분류: `evidence_type=DERIVED, status=CONFIRMED`

## 이닝(Inning)이란

한 경기는 보통 9번의 "이닝"으로 나뉩니다. 이닝 하나는 두 팀이 각각 한 번씩 공격·수비를 주고받는 단위로, 원정팀이 공격하는 "초"와 홈팀이 공격하는 "말"로 나뉩니다. 9회까지 점수가 같으면 연장전에 들어갑니다.

## 아웃(Out)이 되는 3가지 방식

삼진(스트라이크 3개), 플라이 아웃(친 공을 땅에 떨어지기 전에 잡힘), 포스아웃/태그아웃(주자가 베이스 도착 전에 아웃당함). 한 이닝에 아웃 3개면 공수 교대입니다.

## 스트라이크와 볼, 삼진·볼넷

스트라이크 3개면 삼진, 볼 4개면 볼넷(1루 진루). 초보자가 가장 헷갈리는 규칙: **스트라이크 2개인 상태에서는 파울을 아무리 쳐도 삼진이 되지 않습니다**(2개 미만일 때만 파울이 스트라이크로 카운트됨).

## 안타의 종류

단타(1루)·2루타·3루타·홈런(담장 넘김, 주자 있으면 같이 득점) 순. 만루 상태 홈런은 "만루 홈런"으로 한 번에 4점.

## 포지션 이해하기

투수·포수(배터리) + 1·2·3루수·유격수(내야) + 좌·중·우익수(외야) 총 9명. 처음 본다면 투수·포수·유격수만 눈여겨봐도 충분합니다.

## 구장에서 자주 듣는 용어

더그아웃(선수 대기석, 1루/3루 중 어느 쪽이 홈인지는 구장마다 다름), 불펜(구원투수 대기 공간), 마운드(투수판), 세이브(리드 지킨 마무리 투수 기록), 홀드(리드 지킨 중간 투수 기록).

## 초보자가 자주 헷갈리는 것들

- "스트라이크 2개서 파울 치면 삼진 아니에요?" → 아닙니다, 카운트 그대로 유지.
- "단타=1루타" 등 같은 뜻 다른 표현이 많으니 헷갈리지 않아도 됩니다.
- "홈팀이 왜 나중에 공격해요?" → 마지막 공격권을 홈팀에 줘서 관중 앞 끝내기가 가능한 구조입니다.

# 2부. KBO 리그 고유 규정 (2026시즌 기준, 매 시즌 바뀔 수 있음)

분류: `evidence_type=DERIVED, status=CONFIRMED` — 나무위키·언론 보도 종합. 시즌마다 이사회 결정으로 바뀌는 "제도"라 1부보다 재확인 주기가 짧아야 함(출처는 문서 하단).

| 제도 | 핵심 규칙 |
| --- | --- |
| 지명타자(DH) | 투수 대신 타격만 하는 선수. 수비에 들어가면 그 순간 DH 소멸 → 이후 투수가 직접 타석에 섬. |
| ABS(로봇심판) | 2024년 세계 최초 도입. 카메라가 투구를 추적해 컴퓨터가 스트라이크/볼 판정(약 1초 이내), 존은 타자 신장 비율로 개인마다 계산. |
| 피치클락 | 주자 없을 때 20초/있을 때 25초(2025 정식도입) → **2026시즌 18초/23초로 단축**. 위반 시 투수는 볼, 타자는 스트라이크. |
| 비디오 판독 | 감독 경기당 2회(연장 시 +1회). 홈런·고척돔 천장 타격은 무제한, 2025.8부터 체크스윙도 별도 2회 추가. |
| 외국인 선수 | 보유·등록 3+1명(아시아쿼터 1명 포함), 동시 출전은 2명까지. 투타 비율 제한(3:1 또는 2:2)도 있음. |
| 연장전 | 승부치기 미도입. 2025시즌부터 12회→11회로 단축, 11회까지 무승부면 종료. |
| 우천 규정 | 5회 이전 중단="노게임"(무효), 5회 이후 중단=그 시점 스코어로 "콜드게임" 확정 또는 "서스펜디드"(나중에 이어서 재개). |

# 3부. 직관 관람 실전 팁

분류: `evidence_type=DERIVED, status=CONFIRMED` — 응원가·구호 등 저작권 소지 콘텐츠는 팀 결정에 따라 제외.

- **비 예보 있는 날**: 시작 전 취소 기준은 대략 "시작 3시간 전 시간당 10mm" 또는 "1시간 전 시간당 5mm" 수준(현장 최종 판단은 다를 수 있음). 경기 중 중단돼도 5회를 넘겼으면 결과가 인정되거나 나중에 이어서 하니 표가 무효가 되진 않습니다.
- **파울볼 안전**: 더그아웃 근처·그물 없는 구역에선 항상 경기장 쪽을 주시. 무리하게 잡으려 하지 말고 피하는 게 우선.
- **도착 타이밍**: 라인업은 보통 경기 1~2시간 전 구단 SNS로 발표. 인기 매치업·주말은 게이트가 붐빌 수 있어 여유 있게 도착 권장. 선예매 오픈 시각 등은 `kbo_ticket_policy_structured.csv` 참고.
- **재입장·반입**: 구장·구단마다 다르고 자주 바뀌므로 이 문서에서 확정 안내하지 않음(`재입장규정_검증메모.md`에서 별도 검증 중). 현장 안내를 우선 따르는 걸 권장.
